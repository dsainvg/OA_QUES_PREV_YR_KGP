    Q1. Level-Order Traversal Data Structure

    Topic: trees, data-structures

    A level-order traversal in a binary tree requires which data structure?

    Options: - Stack - Doubly Linked List - Queue - Circular Linked List

    Answer: Queue

    Explanation: Level-order traversal visits the nodes level by level (from top to bottom, left to right). This corresponds to a Breadth-First Search (BFS) on the tree, which is implemented using a Queue (First-In, First-Out data structure).

    Q2. Complexity of the Code Snippet

    Topic: time-complexity, algorithms

    What is the time complexity of the following code snippet?

    int a = 1;

while (a < n) {
    a = a * 2;
}

    Options: - O(n) - O(1) - O(log2 N) - O(2^n)

    Answer: O(log2 N)

    Explanation: The variable a starts at 1 and is multiplied by 2 in each iteration of the loop (a = 1, 2, 4, 8, 16, ...). The loop terminates when a >= n. If the loop runs \(k\) times, then \(2^k \ge n\), which gives \(k \approx \log_2 n\). Hence, the time complexity is \(O(\log_2 n)\).

    Q3. Bandwidth Calculation

    Topic: math, system-design

    A video streaming service provides movies in HD quality, each consuming a bandwidth of 4 Mbps. If the service has 10,000 concurrent users streaming videos, what is the total bandwidth required for the service to function smoothly?

    Options: - 4 Gbps - 40 Gbps - 400 Gbps - 400 Mbps

    Answer: 40 Gbps

    Explanation: Total bandwidth = Number of concurrent users \(\times\) Bandwidth per user $\(\text{Total Bandwidth} = 10,000 \times 4\text{ Mbps} = 40,000\text{ Mbps}\)$ Since \(1\text{ Gbps} = 1,000\text{ Mbps}\), the total bandwidth required is: $\(40,000\text{ Mbps} = 40\text{ Gbps}\)$

    Q4. Cache Mechanics

    Topic: cache, algorithms

    Consider a caching system that uses the LRU (Least Recently Used) cache replacement policy. The cache size is limited to 3 items. The following sequence of items is accessed: A, B, C, A, D, E. After these accesses, which items are in the cache?

    Options: - A, C, E - A, D, E - B, D, E - C, D, E

    Answer: A, D, E

    Explanation: We simulate the cache of size 3 with the sequence A, B, C, A, D, E. Let the cache state be ordered from Least Recently Used (left) to Most Recently Used (right): 1. Access A: Cache = [A] (Miss) 2. Access B: Cache = [A, B] (Miss) 3. Access C: Cache = [A, B, C] (Miss) 4. Access A: Cache = [B, C, A] (Hit, A becomes most recently used) 5. Access D: Cache = [C, A, D] (Miss, evict LRU item B) 6. Access E: Cache = [A, D, E] (Miss, evict LRU item C)

    Thus, the final items in the cache are A, D, E.

    Q5. Identify Tasks with O(1) Time Complexity

    Topic: time-complexity, data-structures

    An example of O(1) task is... Select one or more options.

    Options: - Printing a character to screen - Incrementing a variable - Inserting a node in non-empty binary search tree - Adding element at the beginning of non-empty array

    Answer: Printing a character to screen, Incrementing a variable

    Explanation: - Printing a character to screen: Takes constant time, \(O(1)\). - Incrementing a variable: A primitive operation that takes constant CPU cycles, \(O(1)\). - Inserting a node in non-empty BST: Requires traversing down the height of the tree, which takes \(O(h)\) time where \(h\) is the height of the tree (\(O(\log n)\) in balanced BST, \(O(n)\) in worst case). - Adding element at the beginning of non-empty array: Requires shifting all \(n\) existing elements to the right, which takes \(O(n)\) time.

    Q6. Generate Missing Data

    Topic: binary-search, greedy, strings

    A data scientist is working on a project where they need to train a language model to recognize certain patterns in text data. The model requires a specific set of characters as input to learn from. However, some of the characters needed for training are missing from the dataset, represented in the form of a string called dataToBeGenerated.

    To acquire these missing characters, the data scientist has a tool that can generate multiple copies of a given string. However, the tool can only generate strings of a fixed length, n, and it only accepts one input string to generate missing data.

    Each string generated by the tool incurs a cost, and the more copies of strings generated, the higher the cost. The goal is to minimize the cost while ensuring the data contains all the required characters. The task is to find the lexicographically smallest input string that, when fed into the data generation tool, produces datasets containing all the required characters while minimizing the total cost. If it is not possible to do so, return "-1" as a string.

    Function Signature: 

    def getLexSmallestString(n: int, dataToBeGenerated: str) -> str:
    pass

    Constraints: - \(1 \le n \le 2 \times 10^5\) - \(1 \le |dataToBeGenerated| \le 2 \times 10^5\) - dataToBeGenerated only contains lowercase English letters from 'a' to 'z'.

    Input Format for Custom Testing

    • The first line contains an integer, n.
    • The second line contains the string, dataToBeGenerated.

    Sample Case 0

    Sample Input: 

    4
abacbca
    Sample Output: 
    aabc
    Explanation: The character 'a' appears 3 times, 'b' and 'c' appear twice. Since the number of distinct characters required is not greater than \(n\), it is possible for the tool to generate the required string. There should be 4 letters in the input string. Three are 'a', 'b', and 'c'. The fourth character can be 'a', 'b', or 'c'. - If the fourth character is 'a', the string "aabc" generates all the missing characters in 2 copies. (Since \(2 \times 2 \ge 3\) for 'a', \(2 \times 1 \ge 2\) for 'b' and \(2 \times 1 \ge 2\) for 'c'). - If the fourth character is 'b', the string "abbc" generates all the missing characters in 3 copies. - If the fourth character is 'c', the string "abcc" generates all the missing characters in 3 copies. Thus, "aabc" is the lexicographically smallest string that minimizes the number of copies.

    Sample Case 1

    Sample Input: 

    3
aabaabba
    Sample Output: 
    aab
    Explanation: The character 'a' appears 5 times and 'b' appears thrice. Since the number of distinct characters required is not greater than \(n\) (2 <= 3), it is possible to generate the required string. There can be 3 letters in the input string, with 2 of them being 'a' and 'b'. - If the third character is 'a', the string "aab" generates all the missing characters in 3 copies. (Since \(3 \times 2 \ge 5\) for 'a', \(3 \times 1 \ge 3\) for 'b'). - If the third character is 'b', the string "abb" generates all the missing characters in 5 copies. Thus, "aab" is the optimal string.

    Answer: 

    import math

def getLexSmallestString(n: int, dataToBeGenerated: str) -> str:
    # Count frequencies of each character in dataToBeGenerated
    counts = {}
    for char in dataToBeGenerated:
        counts[char] = counts.get(char, 0) + 1

    num_distinct = len(counts)

    # If the number of unique characters exceeds the permitted length n,
    # it is impossible to satisfy the condition.
    if num_distinct > n:
        return "-1"

    # Binary search for the minimum number of copies K
    low = 1
    high = len(dataToBeGenerated)
    ans_K = high

    while low <= high:
        mid = (low + high) // 2
        # Check if it is possible to achieve K = mid
        total_len = 0
        for count in counts.values():
            total_len += math.ceil(count / mid)
        if total_len <= n:
            ans_K = mid
            high = mid - 1
        else:
            low = mid + 1

    # Reconstruct the frequencies for each character based on ans_K
    freq = {chr(c): 0 for c in range(ord('a'), ord('z') + 1)}
    for char, count in counts.items():
        freq[char] = math.ceil(count / ans_K)

    # Distribute the remaining slots to 'a' to make the string lexicographically smallest
    current_sum = sum(freq.values())
    rem = n - current_sum
    freq['a'] += rem

    # Construct the lexicographically smallest sorted string
    result = []
    for c in range(ord('a'), ord('z') + 1):
        char = chr(c)
        if freq[char] > 0:
            result.append(char * freq[char])

    return "".join(result)
